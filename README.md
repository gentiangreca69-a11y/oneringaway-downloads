# OneRingAway — app downloads

This repository holds the installable Android app for OneRingAway (the AI phone receptionist for small businesses). It contains no source code.

## Android (Samsung, Google Pixel, Motorola and others)

1. On your Android phone, open https://www.oneringaway.com/android and tap Download, or download the latest file from the Releases page here.
2. Open the downloaded file (OneRingAway.apk). If the phone asks to allow installs from this source (Chrome or Files), allow it once.
3. Tap Install, then Open. Log in with your OneRingAway email and password.

The iPhone app is on the App Store.
